# Voca-IA 🎓🤖

Página web de orientación vocacional con un chatbot basado en Inteligencia Artificial que ofrece recomendaciones personalizadas sobre carreras profesionales para los estudiantes de la **I.E. San Luis de Gaceno**.

## 🚀 Tecnologías

- Python + Flask
- SQLAlchemy + SQLite
- Flask-Login
- OpenRouter API (IA)
- HTML, CSS, JavaScript

## 📁 Estructura

- `app.py` - Aplicación principal
- `models.py` - Modelos de base de datos
- `templates/` - Plantillas HTML
- `static/` - CSS, JS e imágenes

## ⚙️ Instalación

1. Clonar: `git clone https://github.com/karolgalindo29/voca-ia-oficial.git`
2. Crear entorno: `python -m venv venv`
3. Activar: `venv\Scripts\activate`
4. Instalar: `pip install Flask Flask-SQLAlchemy Flask-Login bcrypt python-dotenv requests`
5. Crear `.env` con las credenciales
6. Ejecutar: `python app.py`
